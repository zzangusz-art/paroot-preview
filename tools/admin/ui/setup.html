파릇 어드민

어드민이 아직 켜지지 않았습니다

서버 환경 변수에 어드민 비밀번호가 없어서 로그인 화면을 열지 않았습니다.

  1. Railway → 프로젝트 beneficial-adventure → 서비스 paroot-preview → Variables
  2. ADMIN_PASSWORD에 어드민 비밀번호를 넣습니다(12자 이상 권장).
  3. 글·공지 저장을 쓰려면 GITHUB_TOKEN(저장소 Contents 읽기·쓰기 권한)도 넣습니다.
  4. 방문 통계를 배포 뒤에도 남기려면 볼륨을 붙이고 DATA_DIR을 그 경로로 둡니다.

저장하면 서버가 다시 시작되고 이 주소에서 로그인할 수 있습니다.
